# kaml

kaml is the YAML library of Davils: a strict, lossless YAML 1.2 parser, emitter and document toolkit for Kotlin on
the JVM and on WebAssembly (`wasmJs`), built on [Kore](https://github.com/davils-com/kore) and safe to feed with
untrusted input. It is in development and not yet published.
